How the code is read

The box holds the body of function choose(seq). seq is one arrival order, an array of the visitors' scores 1..N. Return the 0-based index of the visitor who gets the ad, or -1 if the ad is never shown. The page runs it once per permutation. Under the first objective it counts a win when seq[index] === N. Under the second it averages seq[index] over all permutations, with -1 scoring 0. In both cases a strategy should only compare visitors it has already seen; peeking ahead at seq defeats the point.
